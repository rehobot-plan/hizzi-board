## 1. 진입 시 자동 read

진입 발동과 동시에 아래 **다섯**을 이 순서로 읽는다.

1. `CLAUDE.md` — 이 앱이 무엇이고 무엇이 어디 있는지
2. `md/core/session.md` — 이 문서
3. `md/core/coding-rules.md` — 코드 쓰기 전 체크리스트
4. `md/core/master.md` — 구조 지도
5. `md/log/todo.md` — 현재 작업 현황

공정은 이 목록에 없다 — 거버넌스 하네스가 단일 출처다.

### 주입 확인

읽은 다섯이 비었거나 손상됐는지 내용으로 확인한다. 하나라도 실패하면 즉시 오너에게 보고하고 진행을 중단한다.

## 2. 이 폴더의 MD 층

거버넌스 층은 이 폴더에 **없다**(부모 폴더에 있다). 그러므로 여기 있는 MD는 전부 도메인 층이고, 수정 절차는 거버넌스 `rules.md` 문서 수정 절차 — 도메인 층을 따른다.

**다만 셋은 오너 승인 후 고친다** — `CLAUDE.md`(앱 진입점) · 이 문서 · `board-principles.md`(판단 원칙). 앱의 규약을 담는 자리라 자율 수정 대상이 아니다.

`todo.md`·`done.md`는 예외다 — 공장이 완료 보고(하네스 1-6)에서 직접 갱신한다.
