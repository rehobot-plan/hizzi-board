## 1~2. 탐색·구현

**읽고 지웠다** — `.claude/settings.json`(54줄). `agents/`·`commands/` 는 안 건드린다.

**층 세션에서 안 실린다** — 세션 진입 자리가 층이라 이 폴더의 설정은 로드되지 않는다.

**그런데 이 파일은 층과 다른 것을 들고 있었다** — 그래서 읽는 사람이 그대로 믿으면 틀린다.

| 이 파일이 든 것 | 층은 |
|---|---|
| `ask`: `git push*` · `npm install` · `npm install *` | `ask` 가 **비어 있다** |
| `deny`: `rm -rf*` | 층은 `rm -rf /`·`~*` 만 — **이쪽이 더 넓다** |
| `deny`: `Write(.env*)` | 층은 `Edit(.env*)` — **막는 도구가 다르다** |
| `UserPromptSubmit` 훅 → `scripts/preflight.ps1` | 층에 없다 |

**넷 다 안 서고 있었다.** 특히 `ask` 셋은 *"push 하면 물어본다"* 로 읽히는데 실제로는 안 물었다.

## 3. 빌드 검증

**추적 파일 삭제라 되돌릴 수 있다.**

**빌드 검증(`npm run lint`·`build`·`test:unit`)은 안 돌렸다** — 설정 파일 하나를 지웠고 소스에 안 닿는다. **도구 부재가 아니라 공정의 판단이다.**

**못 쟀다 — 이 삭제가 아무것도 안 끈다는 것은 실행으로 확인할 수 없다.** 권한 파일은 세션 시작에 읽히고, 안 실린다는 전제는 훅 등록 경로로 세운 것이지 실행으로 세운 것이 아니다.

## 넘기는 값

### 1) 등록 없이 남는 스크립트 하나

**`scripts/preflight.ps1`(670바이트)이 이제 아무 데서도 안 불린다.** 그것을 부르던 유일한 자리가 방금 지운 파일의 `UserPromptSubmit` 훅이었다.

**안 지웠다 — 이 회차 범위 밖이다.** 되살릴 등록 블록을 여기 남긴다.

```json
"hooks": {
  "UserPromptSubmit": [
    { "matcher": "", "hooks": [ { "type": "command", "command": "powershell -ExecutionPolicy Bypass -File scripts/preflight.ps1" } ] }
  ]
}
```

**갈래가 둘이다** — 이 앱을 갈아엎을 때 그 스크립트가 하던 일을 다시 세우거나, 필요 없으면 그때 함께 지운다. **지금 정하지 않는다** — 그 회차가 화면과 함께 정할 자리다.

### 2) 이 앱은 갈아엎기 대기 중이다

**오너 결정으로 게이트 넓히기 대상에서 빠져 있다**(2026-08-19). 이 삭제는 그것과 다른 자리다 — **안 실리는 설정을 걷는 일**이고 갈아엎기와 안 부딪힌다.

### 3) 안 쟀다

- **다른 기계(D·C)에 이 앱의 `.claude/settings.local.json` 이 있는지 안 봤다.** 이 맥에는 없다.
