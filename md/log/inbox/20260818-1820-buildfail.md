## ⑷ 고치기 — 저장소 자리가 아니다

환경변수 등록은 대시보드·CLI 쓰기이고 이 회차는 읽기만 열려 있다. **저장소 안에서 닫을 길은 없다** — 값 자체가 저장소 밖에 있어야 하는 것들이다(무시 대상 `.env.local` 이 그 증거다).

**오너 걸음 (그대로 밟으면 된다)**

1. Vercel 대시보드 → 프로젝트 **hizzi-board** → Settings → Environment Variables.
2. 이미 있는 여섯(위 표의 Production 목록)을 하나씩 열어 **Preview 를 함께 체크**한다. 값은 프로덕션과 같은 것을 쓴다.
3. 여섯을 다 마치면 가지를 하나 push 하거나 실패한 배포에서 Redeploy 를 누른다.
4. 확인은 이 문서 미리보기 절대로 — `state` 가 `success` 인지 보고, 그다음 `curl {미리보기주소}/version.txt` 가 `{커밋해시 앞 12자}-{시각}` 을 내는지 본다.

`cd {레인} && npm run lint | tail -5` — 「deny floor: cd-prefixed command blocked — the condition that failed is: segment 2 is joined by | instead of && …」. **내 손버릇이고 규약이 이미 적는 자리다.** 지목대로 파이프를 걷고 한 번 다시 쳐서 섰다.

## 곁다리

- **`vercel link` 를 안 했다.** `--scope` 만으로 로그가 읽혔고, 환경변수는 `--project` 를 더하니 읽혔다. 그래서 `.vercel/` 도 안 생겼고 `.gitignore` 가 고쳐지는 자리도 안 지났다(전언이 경계한 그 자리다).
- 로컬 판번호는 `dev-…` 로 찍힌다 — git 커밋이 부른 배포가 아니라서다. 이 문서 미리보기 절이 이미 적는 그대로다.
